Django Template Filters Showcase

Basic String Filters

Default Value
{{fname|default:'doaa almaghriby' }}
Result: {{fname|default:'doaa almaghriby' }}
Provides a default value if variable is empty or False
Uppercase
{{fname|upper }}
Result: {{fname|upper }}
Lowercase
{{ fname|lower }}
Result: {{ fname|lower }}
Capitalize First Letter
{{ fname|capfirst }}
Result: {{ fname|capfirst }}
Length
{{ fname|length }}
Result: {{ fname|length }} letters
Slice 2
{{ fname|slice:":2" }}
Result: {{ fname|slice:":2" }}
Add Strings
{{ fname|add:" almaghriby" }}
Result: {{ fname|add:" almaghriby" }}

Additional Useful Filters

Date Formatting
{{ today|date:"Y-m-d" }}
Result: {{ today|date:"Y-m-d" }}
Formats date objects (requires date variable)
Join List
{{ list|join:", " }}
Result: {{ list|join:", " }}
Joins list elements with specified separator
Floatformat
{{ float_num|floatformat:2 }}
Result: {{ float_num|floatformat:2 }}
Rounds floating point number to decimal places
Truncatechars
{{ long_text|truncatechars:20 }}
Result: {{ long_text|truncatechars:20 }}
Truncates string after specified number of chars
Wordcount
{{ text|wordcount }}
Result: {{ text|wordcount }} words
Random
{{ list|random }}
Result: {{ list|random }}
Dictsort
{{ dict_list|dictsort:"name" }}
Sorts list of dictionaries by key

Advanced Filters

Safe (Mark as HTML safe)
{{ html_content|safe }}
Marks string as HTML safe (won't be escaped)
Urlize
{{ url_text|urlize }}
Converts URLs in text into clickable links
Line Numbers
{{ code_text|linenumbers }}
Displays text with line numbers
